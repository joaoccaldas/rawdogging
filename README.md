# Rawdogging

3D survival game built with JavaScript and Three.js. The definitive version of the Rawdog game series.

## Features

- Full 3D world with Three.js
- Armor and equipment system
- Quest and side-quest system
- Home beacon and save system
- Death screen with statistics
- Sound management

## Getting Started

Open `index.html` in a browser.

## Lineage

Rawdogging is the active 3D continuation of the Rawdog game family.

- `rawdog` is the earlier 2D survival experiment and remains useful as a separate predecessor.
- `rawdog3d` is archived and already points to this repository as the active 3D version.

## Project context

This is a personal, self-directed learning project by João Caldas. I use this project to learn Three.js, game-world architecture, rendering, persistence, interaction systems, performance, and AI-assisted game development through hands-on iteration.

AI tools are used extensively during research, design, coding, debugging, testing, asset ideation, and documentation. AI-generated suggestions are treated as inputs to review, not proof of correctness. Rendering, collision, persistence, performance, and gameplay behavior should be validated.

## Portfolio role
